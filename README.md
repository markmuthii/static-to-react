# 🧑‍💼 Random User Directory (HTML, CSS & JavaScript Version)

This is a simple, responsive web application that displays a list of random user profiles using the [Random User API](https://randomuser.me/). It includes two pages:

- **Home Page (`index.html`)** — Displays a list of random users.
- **User Detail Page (`user.html`)** — Displays detailed information about a selected user.

This version is built entirely with **HTML**, **CSS**, and **vanilla JavaScript**, with no frameworks or libraries.
